# 運転環境認識（試作）— ステップ1

車内にスマホを固定し、背面カメラの映像と GPS 速度を表示する Web アプリ（PWA）です。
研究・試作用で、**安全装置ではありません**。

## できること（ステップ1）

- 背面カメラの映像を背景に表示
- GPS による現在速度の表示（取得できないときは `--`。0 とは区別）
- 画面の自動消灯の防止（Wake Lock API）
- 車線・標識・横断歩道・歩行者の表示欄（**すべて「未確認」。認識は未実装**）
- 制限速度の表示欄（標識認識の実装まで常に「未確認」）
- カメラ・GPS・常時点灯・処理（fps）の状態を画面下に表示
- カメラが使えない場合の理由表示と再試行
- 画面を戻したときのカメラ再開と、常時点灯の取り直し

## できないこと

- 車線・標識・横断歩道・歩行者の認識（ステップ2以降）
- 画面ロック中・他のアプリを前面にしている間の動作（ブラウザの仕様）
- オフライン起動（初回の読み込みにはネットワークが必要。サービスワーカーは未実装）

## 認識結果の 3 つの状態

| 状態 | 画面の表示 | 意味 |
|---|---|---|
| 検出 | 水色の塗りつぶし | 検出できた |
| 検出されず | 白い枠 | 映像は確認できたが検出されなかった（「いない」ではない） |
| 未確認 | 橙の点線＋斜線 | 確認できていない（未実装・映像なし・処理停止） |

処理が止まったときは、前回の結果を残さず「未確認」に戻します。

## ファイル構成

```
index.html              画面
css/style.css           デザイン
js/main.js              全体の制御・画面更新
js/camera.js            カメラ取得（失敗の種類を区別）
js/gps.js               GPS 速度の取得
js/wakelock.js          画面常時点灯
js/pipeline.js          映像フレームを認識モジュールへ渡す
js/recognizers/index.js 認識モジュールの共通インターフェースとスタブ
js/format.js            速度変換・GPS 状態判定（テスト対象）
test/format.test.mjs    単体テスト
manifest.webmanifest    ホーム画面追加用
_headers                Cloudflare Pages 用（カメラ・位置情報の許可ポリシー）
```

ステップ2以降は、`js/recognizers/index.js` のスタブを実装に差し替えます。
画面側（`main.js`）は変更不要です。

## パソコンで動かす

```
npm test      # 単体テスト（Node.js 20 以上）
npm start     # http://localhost:8080 で配信
```

`localhost` は HTTPS でなくてもカメラが使えます。スマホの実機で試すときは、
下の手順で公開して HTTPS の URL を使ってください。

## 公開する（GitHub → Cloudflare Pages）

1. このフォルダの中身を GitHub のリポジトリに置く（非公開リポジトリで構いません）。
2. Cloudflare の管理画面で Workers & Pages → Create → Pages → Connect to Git を選び、リポジトリを選ぶ。
3. 設定は次のとおり（画面の表記は変わることがあります）。
   - Framework preset: None
   - Build command: 空欄
   - Build output directory: `/`
4. Save and Deploy を押す。`https://（プロジェクト名）.pages.dev` で開けます。

一般公開したくない場合は、URL を人に教えないのが最低限です。
URL を知っていれば誰でも開けるので、制限したい場合は Cloudflare Access（メール認証）を検討してください。

## 実機テスト（ステップ1の確認項目）

iPhone は Safari、Android は Chrome で開いて確認します。**最初は停車中に行ってください。**

| 確認項目 | 期待する結果 |
|---|---|
| 「開始」を押す | カメラと位置情報の許可を求められる |
| 許可する | 背面カメラの映像が出る。下に「カメラ 動作中」「処理 ○fps」 |
| 屋外で GPS を受信 | 「GPS 受信中 ±○m」が出る |
| 走行（安全な場所で、同乗者が確認） | 速度が出る。車の速度計と大きくずれないか |
| 停車直後 | 速度が `0` になるか `--` になるか（端末で違う可能性あり） |
| 画面を放置 | 自動で消えない（下に「常時点灯 有効」） |
| 別のアプリに切り替えて戻る | カメラが再開する |
| 縦・横に回す | どちらも崩れず読める |
| カメラ拒否 | 理由と「再試行」が出る |
| 標識・車線などの表示 | すべて「未確認」のまま |

## 動作確認の範囲（この環境で確認したこと）

- 単体テスト 12 件（速度変換、null と 0 の区別、GPS 途絶、制限速度不明時の判定）
- Chromium での動作確認（疑似カメラ・疑似 GPS）。開始、速度表示、null、更新途絶、
  位置情報拒否、カメラ拒否、非対応、縦横表示を確認

**まだ確認していないこと:** iPhone Safari・Android Chrome の実機、実際の GPS 速度、
実際の Wake Lock、ホーム画面に追加した状態での動作。上の実機テストで確認してください。
